# AI provider marks

The monochrome marks of the AI services the AI usage plugin reads
(`web/src/plugins/usage/logos.tsx`), from Lobe Icons
(https://github.com/lobehub/lobe-icons, MIT, `LICENSE`), npm package
`@lobehub/icons-static-svg` 1.102.0, `icons/<name>.svg`: their titles and
fixed sizes removed, drawn in the color of the text (`currentColor`). The
marks are the services' trademarks, shown to name the services.
